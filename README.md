# HoopTabs

Live stats and a simulated social feed for **Hoop Land** (PC). It reads your save folder and updates as you play.

## Download

Get **HoopTabs Setup 0.1.0.exe** from the [latest release](https://github.com/cotanick/hooptabs-download/releases/latest).

## First run on Windows

The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC".
Click **More info**, then **Run anyway**.

## Notes

- Your game files are only read, never changed.
- Everything stays on your PC unless you turn on Mobile sync.
